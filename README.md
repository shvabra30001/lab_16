## Описание проекта
В работе освоены методы сбора, проверки и сохранения данных из внешних источников:
- отправка HTTP GET-запросов через библиотеку `requests` и проверка статус-кода;
- разбор JSON-ответов и работа со вложенными структурами словарей;
- преобразование данных API в `pandas.DataFrame` и сохранение в форматы `CSV` и `JSON`;
- обнаружение пропусков (`isnull`) и дубликатов (`duplicated`) в данных;
- создание функции автоматического бэкапа выгрузки с текущей датой в имени файла.

## Как запустить
1. Установите зависимости: `pip3 install -r requirements.txt`
2. Запустите скрипт: `python3 main.py`
